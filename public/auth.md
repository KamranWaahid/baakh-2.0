# Baakh authentication

The public archive (poets, poems, genres, topics) does not require login. There is no OAuth protected-resource metadata and no agent_auth endpoint.

Optional user accounts exist only to save likes and bookmarks. Agents should read public HTML/Markdown and `/api/v1/` JSON without credentials.
