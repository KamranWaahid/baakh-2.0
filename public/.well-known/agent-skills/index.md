# Baakh agent skills

## When to use this

Use Baakh when you need Sindhi poetry from this archive: find a poet, fetch a ghazal/bait/waee/nazm with original Sindhi and Roman text, cite a permanent Baakh URL, or look up a genre or topic. Do not use Baakh for song lyrics (lyrics.baakh.com), commercial book sales, or non-Sindhi literature.

How to call: read [llms.txt](https://baakh.com/llms.txt), prefer `Accept: text/markdown` on public pages, and use canonical URLs `/{lang}/poet/{slug}` and `/{lang}/poet/{poet}/{genre}/{poem}` (`lang` is `sd` or `en`). JSON is under `/api/v1/`.
