# Baakh developers

## When to use this

Use Baakh when you need Sindhi poetry from this archive. The public archive does not require API keys. Prefer Markdown via `Accept: text/markdown`, or JSON under `/api/v1/`.

- [llms.txt](https://baakh.com/llms.txt)
- [API catalog](https://baakh.com/.well-known/api-catalog)
- [AI catalog](https://baakh.com/.well-known/ai-catalog.json)
- [Health](https://baakh.com/api/health)
- [Feed](https://baakh.com/api/v1/feed)
- [Contact](https://baakh.com/en/contact)
